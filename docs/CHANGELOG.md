# 更新日志

## 未发布

### 架构
- 内置下载引擎：从 yt-dlp 源码构建，并自带 ffmpeg / ffprobe / deno，不再依赖系统安装的 yt-dlp、Node.js
- 设置中可在线更新引擎（官方发布 + SHA256 校验），并可恢复内置版本

### 新功能
- 下载任务列表：实时进度、速度、剩余时间，可取消，完成后可打开文件或所在位置
- 字幕管理接入真实数据：单独下载字幕，下载视频时可勾选字幕嵌入或另存
- 批量下载：播放列表自动展开，统一格式、并发数、跳过已下载、出错时继续均已生效
- 支持粘贴整段分享文案（如抖音分享口令），自动提取链接
- 历史记录持久化，支持搜索、打开文件和所在位置
- 报错全部显示为中文，并附处理建议

### 修复
- 「从浏览器获取 Cookie」此前从未生效
- Chrome Cookie 库被误选为组件的小数据库，导致登录态丢失
- 抖音解析失败（风控 403），新增抖音插件修补
- 仅音频下载实际未提取音频
- 签名后内置 deno 无法运行导致 YouTube 解析失败

## v1.0.0 (2026-06-25)

### 新功能
- 🎉 首次发布
- 📥 单视频下载：支持粘贴链接解析和下载
- 📦 批量下载：支持多链接输入和文件导入
- 🎬 格式选择：支持 1080p/720p/480p/360p 视频质量
- 🎵 音频提取：支持 MP3/AAC/FLAC/OPUS 格式
- 📝 字幕管理：支持下载和嵌入字幕（SRT/VTT/ASS）
- 🍪 Cookie 管理：支持浏览器 Cookie 和手动 Cookie 文件
- ⚙️ 后处理：嵌入字幕、封面、元数据、章节、SponsorBlock 去广告
- 📋 历史记录：自动保存下载记录，支持搜索和删除
- ⚙️ 设置：保存路径、文件名模板、代理、限速等
- 🌐 跨平台：支持 Windows 和 macOS

### 技术实现
- 基于 Tauri 2.0 + React + TypeScript 构建
- 使用 yt-dlp 作为下载引擎
- 苹果风格简约 UI 设计
- 内嵌 yt-dlp 二进制文件，用户无需额外安装
