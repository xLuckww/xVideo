# 更新日志

## v1.0.0 (2026-06-25)

### 新功能
- 🎉 首次发布
- 📥 单视频下载：支持粘贴链接解析和下载
- 📦 批量下载：支持多链接输入和文件导入
- 🎬 格式选择：支持 1080p/720p/480p/360p 视频质量
- 🎵 音频提取：支持 MP3/AAC/FLAC/OPUS 格式
- 📝 字幕管理：支持下载和嵌入字幕（SRT/VTT/ASS）
- 🍪 Cookie 管理：支持浏览器 Cookie 和手动 Cookie 文件
- ⚙️ 后处理：嵌入字幕、封面、元数据、章节、SponsorBlock 去广告
- 📋 历史记录：自动保存下载记录，支持搜索和删除
- ⚙️ 设置：保存路径、文件名模板、代理、限速等
- 🌐 跨平台：支持 Windows 和 macOS

### 技术实现
- 基于 Tauri 2.0 + React + TypeScript 构建
- 使用 yt-dlp 作为下载引擎
- 苹果风格简约 UI 设计
- 内嵌 yt-dlp 二进制文件，用户无需额外安装
