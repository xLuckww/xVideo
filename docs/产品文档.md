## 1. 产品简介

### 什么是 xVideo？

xVideo 是一款基于 yt-dlp 的图形化视频下载工具，支持从 YouTube、B站、抖音、小红书等 1000+ 网站下载视频。

### 核心特点

| 特点 | 说明 |
|------|------|
| 🎯 简单易用 | 粘贴链接即可下载，无需命令行知识 |
| 🌐 多平台支持 | 支持 Windows 和 macOS |
| 🎬 多格式选择 | 支持多种视频质量和音频格式 |
| 📦 批量下载 | 一次处理多个视频 |
| 🎵 音频提取 | 支持提取纯音频 |
| 📝 字幕管理 | 支持下载和嵌入字幕 |

## 2. 安装指南

### 2.1 Windows 安装

**方式一：EXE 安装包（推荐）**
1. 下载 `xVideo_1.0.0_x64-setup.exe`
2. 双击运行安装程序
3. 按照提示完成安装
4. 桌面会出现 xVideo 图标

**方式二：MSI 安装包**
1. 下载 `xVideo_1.0.0_x64.msi`
2. 双击运行，按向导安装

### 2.2 macOS 安装

1. 下载 `xVideo_1.0.0_aarch64.dmg`
2. 双击打开 DMG 文件
3. 将 xVideo.app 拖入 Applications 文件夹
4. 首次打开可能需要在"系统设置 → 隐私与安全性"中允许

### 2.3 系统要求

| 平台 | 最低要求 |
|------|----------|
| Windows | Windows 10 64位 |
| macOS | macOS 11.0 (Apple Silicon) |

## 3. 功能说明

### 3.1 下载视频

**基本流程：**
1. 打开 xVideo，进入"下载"页面
2. 在输入框粘贴视频链接
3. 点击"解析"按钮
4. 等待解析完成，选择视频格式
5. 点击"开始下载"

**支持的格式：**
- 视频：1080p / 720p / 480p / 360p
- 音频：MP3 / AAC / FLAC / OPUS
- 字幕：SRT / VTT / ASS

### 3.2 批量下载

1. 切换到"批量下载"页面
2. 每行输入一个视频链接，或点击"导入文件"选择 txt 文件
3. 点击"解析链接"
4. 等待所有链接解析完成
5. 点击"开始批量下载"

**批量设置：**
- 统一格式：设置所有视频的下载格式
- 并发下载数：同时下载的视频数量
- 跳过已下载：自动跳过历史记录中存在的视频

### 3.3 Cookie 管理

**为什么需要 Cookie？**
部分网站（如抖音、YouTube）的反爬机制要求请求携带浏览器 Cookie，否则无法解析视频。

**启用 Cookie：**
1. 在下载页面找到"启用 Cookie"开关
2. 打开开关后，选择 Cookie 来源

**方式一：从浏览器获取**
- 选择你常用的浏览器（Chrome/Firefox/Safari/Edge）
- 需要先用该浏览器访问过目标网站

**方式二：手动选择 Cookie 文件**
- 安装浏览器扩展（如 Get cookies.txt LOCALLY）
- 登录目标网站
- 导出 cookies.txt 文件
- 在 xVideo 中选择该文件

**各平台 Cookie 需求：**

| 平台 | 是否需要 Cookie |
|------|----------------|
| YouTube | 需要 |
| B站 | 通常不需要 |
| 抖音 | 需要 |
| 小红书 | 通常不需要 |

### 3.4 后处理选项

| 选项 | 说明 |
|------|------|
| 嵌入字幕 | 将字幕文件嵌入视频中 |
| 嵌入封面 | 将视频缩略图作为封面嵌入 |
| 嵌入元数据 | 添加标题、作者等元数据信息 |
| 嵌入章节 | 添加视频章节标记 |
| 去除广告 | 通过 SponsorBlock 自动跳过赞助内容 |

### 3.5 字幕管理

- 查看视频可用的字幕列表
- 下载指定语言的字幕
- 支持 SRT、VTT、ASS 格式
- 可将字幕嵌入视频文件

### 3.6 历史记录

- 自动记录所有下载任务
- 支持按标题搜索
- 支持删除单条记录或清除全部
- 点击"打开"可直接打开已下载的文件

### 3.7 设置

**常规设置：**
- 默认保存路径
- 文件名模板（支持变量：%(title)s, %(id)s, %(uploader)s）
- 默认视频/音频格式

**网络设置：**
- 代理服务器（HTTP/SOCKS5）
- 下载限速
- 重试次数
- 并发分片数

**高级设置：**
- 保留下载记录（保存下载历史，批量下载时据此跳过已下载的视频）
- 下载完成后关机
- 使用系统代理
- Cookie 来源

## 4. 常见问题

### Q1: 无法解析 YouTube 视频
**原因：** YouTube 常要求验证"不是机器人"，或页面校验需要 JavaScript 运行时（xVideo 已内置 deno）。
**解决：**
- 在下载页面启用 Cookie 并选择已登录 YouTube 的浏览器
- 首次读取浏览器 Cookie 需在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」中授权 xVideo
- 若持续失败，到「设置 → 下载引擎」检查更新

### Q2: 无法解析抖音视频
**原因：** 抖音强制要求浏览器 Cookie。
**解决：**
1. 用 Chrome 打开 douyin.com 浏览几秒
2. 在 xVideo 下载页面启用 Cookie
3. 选择"从浏览器获取" → Chrome
4. 或导出 cookies.txt 文件手动选择

### Q3: B站视频 412 错误
**原因：** B站的反爬机制检测到异常请求。
**解决：**
- 关闭代理服务器
- 使用 Cookie（登录 B 站后导出）
- 到「设置 → 下载引擎」检查更新

### Q4: 下载的视频没有声音
**原因：** B站等网站将音视频分开存储。
**解决：** xVideo 已自动处理音视频合并，确保选择了包含音频的格式。

### Q5: 如何更新下载引擎？
进入「设置 → 下载引擎」，点击「检查更新」。新版引擎来自 yt-dlp 官方 GitHub 发布，校验 SHA256 后启用；
如有问题可点击「恢复内置版本」。xVideo 不使用、也不需要系统中安装的 yt-dlp。

### Q6: 下载路径在哪里修改？
进入"设置" → "常规设置" → "默认保存路径"，点击"浏览"选择新路径。

## 5. 技术说明

### 5.1 架构

```
前端 (React) ←→ Tauri IPC ←→ 后端 (Rust) ←→ 内置 yt-dlp 引擎 + ffmpeg + deno
```

xVideo 自带全部运行组件，不依赖系统中安装的 Python、yt-dlp、ffmpeg 或 Node.js：

| 组件 | 说明 |
|------|------|
| yt-dlp 引擎 | 从 yt-dlp 源码以 PyInstaller onedir 构建，位于应用包 `Contents/Resources/engine/` |
| ffmpeg / ffprobe | 静态构建，用于合并音视频、提取音频、嵌入字幕/封面 |
| deno | YouTube 页面校验所需的 JavaScript 运行时 |
| yt-dlp 插件 | xVideo 的站点修补（如抖音），位于 `Contents/Resources/yt-dlp-plugins/` |

调用引擎时会加上 `--ignore-config --no-plugin-dirs`，不读取用户本机的 yt-dlp 配置和插件，保证行为一致。

### 5.2 下载任务

每个下载任务对应一个独立的引擎进程，可单独取消（会连同 ffmpeg 子进程一起结束）。
进度通过 `--progress-template` 和 `--print` 输出机器可读的行，后端解析后按任务 ID 推送给界面：

```
XVP {"status": "downloading", "downloaded_bytes": ..., "total_bytes": ..., "speed": ..., "eta": ...}
XVS downloading | processing
XVF "/path/to/output.mp4"
```

### 5.3 Cookie 工作原理

**浏览器 Cookie：** xVideo 先定位浏览器 profile 的主 Cookie 库，复制到临时目录后交给引擎读取
（避免 yt-dlp 误选 Chrome 组件的同名小数据库），任务结束即删除。macOS 上需要「完全磁盘访问权限」。

**手动 Cookie 文件：** 使用 Netscape 格式的 cookies.txt。

### 5.4 报错与日志

界面上的报错全部翻译为中文并附处理建议；原始信息可通过「复制错误信息」获取。
完整的引擎日志位于 `~/Library/Logs/com.xvideo.desktop/`（`parse.log`、`download-errors.log`）。
