# xVideo 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
xVideo - 智能视频下载工具

### 1.2 产品定位
一款基于 yt-dlp 开源引擎的跨平台桌面视频下载应用，面向普通用户提供简洁直观的视频下载体验。

### 1.3 目标用户
- 需要离线观看视频的普通用户
- 需要批量下载视频的内容创作者
- 需要提取视频音频的用户
- 需要下载视频字幕的学习者

### 1.4 产品目标
- 降低视频下载的技术门槛，让不懂命令行的用户也能轻松使用
- 支持主流视频平台（YouTube、B站、抖音、小红书等 1000+ 网站）
- 提供跨平台一致的用户体验（Windows / macOS）

### 2.2 Cookie 管理（重点）

#### 问题背景
部分网站（如抖音、YouTube）的反爬机制要求请求携带浏览器 Cookie，否则无法解析视频。

#### 解决方案
在下载页面提供 Cookie 配置入口，支持两种方式：

**方式一：浏览器 Cookie**
- 选择浏览器（Chrome/Firefox/Safari/Edge）
- 自动读取浏览器中的 Cookie
- 需要先用对应浏览器访问过目标网站

**方式二：手动 Cookie 文件**
- 导出 Netscape 格式的 cookies.txt 文件
- 手动选择文件路径
- 适用于浏览器 Cookie 无法使用的情况

#### 优先级逻辑
1. 手动 Cookie 文件 > 浏览器 Cookie > 不使用 Cookie
2. 用户可随时启用/禁用 Cookie

## 3. 非功能需求

### 3.1 性能要求
- 应用启动时间 < 2 秒
- 视频解析时间 < 5 秒（取决于网络）
- 内存占用 < 200MB

### 3.2 兼容性
- **Windows**: Windows 10 及以上
- **macOS**: macOS 11.0 及以上（Apple Silicon）
- **浏览器**: Chrome/Firefox/Safari/Edge（用于 Cookie）

### 3.3 安全性
- 不存储用户密码
- Cookie 仅用于本地请求，不上传到任何服务器
- 下载内容仅保存在用户指定的本地路径

## 4. 技术架构

### 4.1 技术栈
| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 19 | UI 组件和状态管理 |
| 开发语言 | TypeScript | 类型安全 |
| 桌面框架 | Tauri 2.0 | 跨平台桌面应用 |
| 后端语言 | Rust | Tauri 原生后端 |
| 下载引擎 | yt-dlp | 视频解析和下载 |
| 状态管理 | Zustand | 轻量级状态管理 |

### 4.2 架构图
```
┌─────────────────────────────────────────────┐
│              用户界面 (React)                │
│  ┌─────────┐ ┌─────────┐ ┌───────────────┐ │
│  │ URL输入  │ │格式选择  │ │ 下载进度/历史 │ │
│  └─────────┘ └─────────┘ └───────────────┘ │
└──────────────────┬──────────────────────────┘
                   │ Tauri IPC
┌──────────────────▼──────────────────────────┐
│            Tauri 后端 (Rust)                 │
│  ┌──────────────┐  ┌──────────────────────┐ │
│  │ 进程管理      │  │ yt-dlp 二进制        │ │
│  │ (调用CLI)     │←→│ (内嵌在app内)        │ │
│  └──────────────┘  └──────────────────────┘ │
└─────────────────────────────────────────────┘
```

### 4.3 数据流
1. 用户粘贴 URL → 前端发送到 Rust 后端
2. Rust 后端调用 yt-dlp 获取视频信息（JSON）
3. 前端解析并展示格式列表
4. 用户选择格式并点击下载
5. Rust 后端执行 yt-dlp 下载命令
6. 实时解析 stdout 输出，更新前端状态

- **设计语言**: 苹果风格简约设计

│  批量下载 │  格式选择列表                   │
│  历史记录 │  后处理选项                     │

│  设置    │                                │

│          │                                │
